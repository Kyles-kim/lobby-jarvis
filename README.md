# Lobby v2

말로 기록하고, 말로 묻고, 회사 문서를 읽고, 밤마다 보고하는 카일님의 개인 비서 (PWA)

- 화면: `index.html` (GitHub Pages) · 서버: `Code.gs` (Google Apps Script)
- 대화 탭: 기록·질문·예약을 Lobby가 알아서 구분
- 호출어: 상단 "호출"을 켜 두면 "안녕 로비", "로비야"로 불러서 대화 (앱 화면이 켜져 있는 동안)
- 문서: 구글 드라이브 "Lobby 문서" 폴더의 PDF·워드·엑셀·파워포인트·구글문서·사진을 읽고 답변
- 보고: 매일 밤 10시 하루 정리 보고서, 원하는 시각에 도는 예약 작업
- API 키·접속 암호는 Apps Script 스크립트 속성에만 저장하며, 이 저장소에는 올리지 않습니다.
